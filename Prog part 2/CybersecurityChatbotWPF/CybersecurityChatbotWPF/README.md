# Cybersecurity Awareness Bot - Part 2 (WPF GUI)

## Features Implemented

### Core Requirements
- ✅ WPF GUI with modern, user-friendly design
- ✅ Voice greeting on application launch
- ✅ ASCII art logo displayed in header
- ✅ Keyword recognition for cybersecurity topics
- ✅ Random responses for phishing tips
- ✅ Conversation flow with follow-up handling
- ✅ Memory to recall user details and interests
- ✅ Sentiment detection for empathetic responses

### GUI Features
- Color-coded chat bubbles (blue for user, light blue for bot)
- Sidebar showing user profile, sentiment, and memory
- Quick topic buttons for easy navigation
- Typing indicator animation
- Responsive layout

### Dynamic Responses
The bot recognizes these topics:
- Password safety (🔐)
- Phishing scams (🎣)
- Safe browsing (🌐)
- Privacy protection (👤)
- Scam awareness (⚠️)
- Email security (📧)

### Memory Features
- Remembers user's name throughout session
- Stores user's preferred cybersecurity topic
- Recalls previous conversation topics for follow-up questions

### Sentiment Detection
Detects and responds appropriately to:
- 😟 Worried - Provides reassuring, simple tips
- 😤 Frustrated - Offers simplified explanations
- 🤔 Curious - Shares interesting cybersecurity facts
- 😊 Happy - Positive, encouraging responses
